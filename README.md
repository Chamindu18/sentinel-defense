## 📖 Overview

**Sentinel Defense** is a fully-featured, browser-based tower defense game built from scratch using vanilla HTML5, CSS3, and JavaScript. Command your defensive towers, strategize your placements, and survive increasingly difficult waves of enemies across 10 challenging stages.

## ✨ Key Features

### 🏗️ Core Gameplay
- **4 Unique Tower Types** - Archer (fast), Cannon (AOE), Frost (slow), Sniper (long-range)
- **5 Enemy Variants** - Normal, Fast, Tank, Flying, and a challenging Boss
- **10 Progressive Waves** - Each wave introduces new enemy compositions and difficulty spikes
- **Strategic Tower Placement** - Build towers on any non-path tile to defend your base
- **Upgrade System** - Towers can be upgraded twice, increasing damage, range, and fire rate
- **Save/Load Functionality** - Resume your game anytime with persistent local storage
- **Real-time Audio Feedback** - Immersive synthesized sound effects for all actions

### 🎨 Visual & Audio
- **Dynamic Particle Effects** - Explosions, hit impacts, and floating damage numbers
- **Screen Shake** - Satisfying camera shake on explosions and base damage
- **Beam Effects** - Visual feedback for sniper shots
- **Wave Announcements** - Dramatic on-screen wave notifications
- **Smooth Animations** - Enemy bobbing, tower rotation, and projectile physics

### 🎯 User Experience
- **Intuitive Build Panel** - Easy tower selection with cost and stat previews
- **Tower Info Popup** - Upgrade and sell towers with real-time stat calculations
- **Range Preview** - Visual feedback when placing towers and hovering over existing ones
- **Keyboard Shortcuts** - Press ESC to pause or cancel actions
- **Responsive Settings** - Volume control and grid toggle options
